# 🗺️ Roadmap

Le projet avance par étapes. Chaque étape fait avancer le mod vers une version **jouable en survie**. Les versions intermédiaires sont publiées sur GitHub ; la publication sur CurseForge et Modrinth attend que le mod soit jouable (voir plus bas).

| Étape | Thème | Objectif | Statut |
|-------|-------|----------|--------|
| 0 | Fondations | Dépôt, outillage, mod vide qui se charge dans le jeu | 🟢 Terminée |
| 1 | Items | Alliages, outils et armes (obtenus en créatif / commande) | 🟢 Terminée |
| 2 | Mécaniques | Création des alliages en jeu : fonderie, recettes, niveaux de chaleur | 🟢 Terminée |
| 3 | Monde | Matières premières : minerais, génération dans le monde, puis armures | 🟢 Terminée |
| 4 | Compatibilité | Intégration avec des mods populaires (Create, Tinkers' Construct…), puis succès et livre de recettes de la fonderie | ⚪ À faire |

## Jalons de publication

- **v0.1.0** : fin de l'étape 1, version de développement publiée sur GitHub (pré-release), non jouable en survie
- **v0.2.0** : fin de l'étape 2, version de développement publiée sur GitHub : les alliages se fabriquent en jeu, mais leurs matières premières restent obtenues en créatif ou par commande
- **v0.3.0** : fin de l'étape 3, pré-release GitHub **à tester** par un petit groupe : les minerais sont dans le monde, et les alliages, les outils et les trois armures se font en survie
- **v1.0.0** : la v0.3.0 validée par les testeurs (avec les corrections éventuelles), publiée avec les pages CurseForge et Modrinth et la page wiki
- **v1.x** : étape 4 (compatibilité, succès, livre de recettes) et évolutions

## Publication sur CurseForge et Modrinth

Le mod est maintenant **jouable en survie** (étapes 1 à 3 terminées). La publication attend la validation de la v0.3.0 par les testeurs ; d'ici là, les versions restent des pré-releases sur GitHub. Suivi : ticket #70, jalon de l'étape 3.

## Reporté

- **Succès** (ticket #75) et **livre de recettes** de la fonderie (ticket #101) : après la v1.0.0, dans l'étape 4.

> Cette roadmap est volontairement sobre : elle sera détaillée étape par étape au fil de l'avancement.
